# MacDroid Clipboard — Plan 4: Clipboard Sync

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Copying on the Mac puts the item on the phone automatically. The phone sends its clipboard to the Mac on demand: a Quick Settings tile, a notification button, the Clipboard tab's "Send now", and a "Copy to Mac" share target. The Mac keeps a searchable history.

**Architecture:**
- **Protocol** (Task 1): `clipboard.set` for text, and an optional `transfer.offer.purpose`.
- **Clipboard images** (Tasks 2–3) ride the existing transfer engines with `purpose = clipboard`. They never ask where to save, are hidden from the Files UI, and are dropped instead of archived.
- **Pure, tested logic in the cores:**
  - Mac (Task 4): `ClipboardRules` (types, limits), `ClipboardHistory` (capacity, persistence, search, image files) and the `ClipboardSync` actor. The actor does echo prevention by change count (spec §8.2).
  - Android (Task 5): `ClipboardHub` (recent items, size limits, send results).
- **Thin platform glue:**
  - Mac (Tasks 6–7): a pasteboard watcher and writer, settings, a "Clipboard from" notification, and the Clipboard page.
  - Android (Tasks 8–9):
    - a `ClipboardBridge` (receive → `ClipboardManager`, images through a `FileProvider`)
    - an invisible `ClipboardSendActivity`
    - the tile, the notification action and the share target
    - the Clipboard tab
- **Cross-platform run and handoff** (Tasks 10–11).

**Tech Stack:**
- **Mac:** Swift 6, Swift Testing, SwiftUI, AppKit `NSPasteboard`/`NSBitmapImageRep`, UserNotifications.
- **Android:** Kotlin 2.4.21, JUnit 4, Compose Material 3, `ClipboardManager`, `TileService`, `androidx.core.content.FileProvider`.

**Spec:** `docs/superpowers/specs/2026-10-13-macdroid-notifications-clipboard-design.md`: §2.1, §2.3, §4, §5, §6 and **§8 (wins over the earlier sections)**. Plan 3 (`2026-10-13-macdroid-notifications-3.md`) is done on the same branch.

- **Limits (spec §2.3, §8.1):**
  - Text: the encoded `clipboard.set` frame must be ≤ 1,048,576 bytes (`ClipboardLimits.maxFrameBytes`, which equals `MacDroidServer.maxMessageSize`).
  - Images: PNG ≤ 10,485,760 bytes (`ClipboardLimits.maxImageBytes`). A larger `clipboard` offer is rejected with `invalid`.
  - Phone recent list: 10 items, in memory only.
  - Mac history: 10, 20 or 50 items, default 20, persisted.
- **Never sent from the Mac (spec §4.1):**
  - pasteboard items with `org.nspasteboard.ConcealedType`, `org.nspasteboard.TransientType` or `org.nspasteboard.AutoGeneratedType`
  - file URLs (`public.file-url`)
  - anything while disconnected (nothing is queued)
  - anything when "Send to phone" is off
- **Echo prevention (spec §8.2):** Mac only. A pasteboard change the Mac made itself (applying a phone item, or **Copy** from history) is identified by its `changeCount` and never sent. Every explicit phone send always sends.
- **Defaults:** Mac "Send to phone" on, "Receive from phone" on, history 20. Android "Get Mac clipboard" on.

## Review Focus

1. **A password-manager copy** (concealed or transient pasteboard types) must never leave the Mac. → Task 4 `concealedTransientAndAutoGeneratedAreIgnored`.
2. **The Mac applying the phone's clipboard** (or a history Copy) must not bounce straight back to the phone. → Task 4 `applyingFromThePhoneIsNotSentBack` and `historyCopyIsNotSent`.
3. **Text whose JSON-escaped frame would exceed 1 MiB** (for example 600,000 newlines, each escaped to two bytes) must be refused, not sent: an oversized frame would kill the WebSocket. → Task 4 `textThatWouldOverflowTheFrameIsRefused`; Task 5 `textThatWouldOverflowTheFrameIsTooLarge`.
4. **A clipboard image** must never show a save panel or "Ask where to save", nor appear in Files/history. → Task 2 `clipboardOfferSkipsAskModeAndHistory`; Task 3 `clipboardOfferUsesTheClipboardTargetAndLeavesNoHistory`.
5. **Shrinking the history** (50 → 10) or "Clear History" must delete the trimmed items' image files, leaving none behind. → Task 4 `trimmingAndClearingDeleteImageFiles`.

```swift
/// What the Mac's clipboard holds, after the app read it (images already converted to PNG).
public enum ClipboardContent: Equatable, Sendable {
    case text(String)
    case image(Data)
}

public enum PasteboardKind: Equatable, Sendable {
    case text, image, ignored
}

/// Which pasteboard items go to the phone (spec §4.1).
public enum ClipboardRules {
    /// Password managers and apps mark private or temporary items with these (nspasteboard.org).
    public static let privateTypes: Set<String> = [
        "org.nspasteboard.ConcealedType", "org.nspasteboard.TransientType", "org.nspasteboard.AutoGeneratedType",
    ]
    public static let fileURLType = "public.file-url"
    public static let imageTypes: Set<String> = ["public.png", "public.tiff"]
    public static let textTypes: Set<String> = ["public.utf8-plain-text", "public.url"]
    private static let zeroID = "00000000-0000-0000-0000-000000000000"

    public static func kind(of types: [String]) -> PasteboardKind {
        let set = Set(types)
        if !set.isDisjoint(with: privateTypes) || set.contains(fileURLType) { return .ignored }
        if !set.isDisjoint(with: imageTypes) { return .image }
        if !set.isDisjoint(with: textTypes) { return .text }
        return .ignored
    }

    /// A single http(s) URL with nothing around it is a link; anything else is text.
    public static func kind(ofText text: String) -> ClipboardItem.Kind {
        let trimmed = text.trimmingCharacters(in: .whitespacesAndNewlines)
        guard !trimmed.contains(where: \.isWhitespace), let url = URL(string: trimmed),
              let scheme = url.scheme?.lowercased(), scheme == "http" || scheme == "https", url.host() != nil else { return .text }
        return .link
    }

    /// Bytes of the `clipboard.set` frame for `text`, JSON escaping included (spec §8.1).
    public static func encodedSize(of text: String) -> Int {
        let message = Message.clipboardSet(ClipboardSet(itemId: zeroID, text: text))
        return (try? MessageCodec.encode(message, id: zeroID))?.utf8.count ?? Int.max
    }

    public static func fitsInAFrame(_ text: String) -> Bool { encodedSize(of: text) <= ClipboardLimits.maxFrameBytes }
}
```

```swift
public struct ClipboardItem: Codable, Equatable, Sendable, Identifiable {

    public var kind: Kind
    /// Text and links; nil for images (stored as files).

    public var direction: Direction
    public var date: Date

    public init(id: String, kind: Kind, text: String?, direction: Direction, date: Date) {
        self.id = id
        self.kind = kind
        self.text = text
        self.direction = direction
        self.date = date
    }

/// The Mac's clipboard history (spec §4.4): newest first, 10/20/50 items, saved in Application Support,
/// images as PNG files beside the JSON. Trimmed and cleared items take their image files with them.
public struct ClipboardHistory: Sendable {
    public static let capacities = [10, 20, 50]
    public static let defaultCapacity = 20

    public let directory: URL
    public let imagesDirectory: URL
    public private(set) var items: [ClipboardItem]
    public private(set) var capacity: Int
    private let store: JSONFileStore<[ClipboardItem]>

    public init(directory: URL, capacity: Int = ClipboardHistory.defaultCapacity) {
        self.directory = directory
        imagesDirectory = directory.appending(path: "images", directoryHint: .isDirectory)
        try? FileManager.default.createDirectory(at: imagesDirectory, withIntermediateDirectories: true)
        store = JSONFileStore(url: directory.appending(path: "history.json"))
        self.capacity = Self.capacities.contains(capacity) ? capacity : Self.defaultCapacity
        items = store.load() ?? []
        trim()
    }

    public static func imageURL(imagesDirectory: URL, id: String) -> URL { imagesDirectory.appending(path: id + ".png") }

    @discardableResult
    public mutating func add(_ content: ClipboardContent, direction: ClipboardItem.Direction, id: String, date: Date) -> ClipboardItem {
        let item: ClipboardItem
        switch content {
        case .text(let text):
            item = ClipboardItem(id: id, kind: ClipboardRules.kind(ofText: text), text: text, direction: direction, date: date)
        case .image(let png):
            try? png.write(to: Self.imageURL(imagesDirectory: imagesDirectory, id: id), options: .atomic)
            item = ClipboardItem(id: id, kind: .image, text: nil, direction: direction, date: date)
        }
        items.insert(item, at: 0)
        trim()
        save()
        return item
    }

    public mutating func setCapacity(_ value: Int) {
        guard Self.capacities.contains(value) else { return }
        capacity = value
        trim()
        save()
    }

    public mutating func clear() {
        items.forEach(removeFiles)
        items.removeAll()
        save()
    }

    public func item(id: String) -> ClipboardItem? { items.first { $0.id == id } }

    public func content(of item: ClipboardItem) -> ClipboardContent? {
        switch item.kind {
        case .text, .link: item.text.map(ClipboardContent.text)
        case .image: (try? Data(contentsOf: Self.imageURL(imagesDirectory: imagesDirectory, id: item.id))).map(ClipboardContent.image)
        }
    }

    public func imageURL(_ item: ClipboardItem) -> URL? {
        guard item.kind == .image else { return nil }
        let url = Self.imageURL(imagesDirectory: imagesDirectory, id: item.id)
        return FileManager.default.fileExists(atPath: url.path(percentEncoded: false)) ? url : nil
    }

    private mutating func trim() {
        while items.count > capacity { removeFiles(items.removeLast()) }
    }

    private func removeFiles(_ item: ClipboardItem) {
        guard item.kind == .image else { return }
        try? FileManager.default.removeItem(at: Self.imageURL(imagesDirectory: imagesDirectory, id: item.id))
    }

    private func save() { try? store.save(items) }
}
```

```swift
import Foundation

public struct ClipboardState: Equatable, Sendable {
    public var items: [ClipboardItem]
    public var capacity: Int
    public var sendToPhone: Bool
    public var receiveFromPhone: Bool
    public var connected: Bool
    public var phoneSupportsClipboard: Bool
    /// Something wasn't sent (too large); shown quietly on the Clipboard page.
    public var note: String?

    public init(
        items: [ClipboardItem] = [], capacity: Int = ClipboardHistory.defaultCapacity, sendToPhone: Bool = true,
        receiveFromPhone: Bool = true, connected: Bool = false, phoneSupportsClipboard: Bool = false, note: String? = nil
    ) {
        self.items = items
        self.capacity = capacity
        self.sendToPhone = sendToPhone
        self.receiveFromPhone = receiveFromPhone
        self.connected = connected
        self.phoneSupportsClipboard = phoneSupportsClipboard
        self.note = note
    }

    public static let empty = ClipboardState()
}

public enum ClipboardEvent: Equatable, Sendable {
    /// Something from the phone is now on the Mac clipboard (the app shows "Clipboard from <phone>").
    case receivedFromPhone(ClipboardItem)
}

/// Clipboard sync on the Mac (spec §4): sends local changes, applies the phone's items, keeps the history.
/// Echo prevention (spec §8.2): `apply` returns the pasteboard change count it produced, and the watcher's
/// report of that change count is ignored.
public actor ClipboardSync {
    public nonisolated var states: AsyncStream<ClipboardState> { stateBroadcast.stream() }
    public nonisolated var events: AsyncStream<ClipboardEvent> { eventBroadcast.stream() }
    public private(set) var state = ClipboardState.empty

    private let stateBroadcast = Broadcast<ClipboardState>(replayLatest: true, initial: .empty)
    private let eventBroadcast = Broadcast<ClipboardEvent>(replayLatest: false)
    private var history: ClipboardHistory
    private var sendOn: Bool
    private var receiveOn: Bool
    private var connected = false
    private var phoneSupports = false
    private var note: String?
    private var ownChanges: Set<Int> = []
    private let now: @Sendable () -> Date
    private let send: @Sendable (Message) async throws -> Void
    private let sendImage: @Sendable (URL) async -> Bool
    private let apply: @Sendable (ClipboardContent) async -> Int
    private var tasks: [Task<Void, Never>] = []

    public init(
        history: ClipboardHistory, sendToPhone: Bool = true, receiveFromPhone: Bool = true,
        now: @escaping @Sendable () -> Date = { Date() },
        send: @escaping @Sendable (Message) async throws -> Void,
        sendImage: @escaping @Sendable (URL) async -> Bool,
        apply: @escaping @Sendable (ClipboardContent) async -> Int
    ) {
        self.history = history
        self.sendOn = sendToPhone
        self.receiveOn = receiveFromPhone
        self.now = now
        self.send = send
        self.sendImage = sendImage
        self.apply = apply
        self.state = Self.makeState(history, sendToPhone, receiveFromPhone, false, false, nil)
        stateBroadcast.yield(state)
    }

    public func attach(to hub: ConnectionHub) {
        guard tasks.isEmpty else { return }
        let messages = hub.messages
        let statuses = hub.statusUpdates
        tasks.append(Task { [weak self] in
            for await message in messages { await self?.handle(message) }
        })
        tasks.append(Task { [weak self] in
            for await status in statuses { await self?.connectionChanged(status) }
        })
    }

    /// The pasteboard changed (spec §4.1). `changeCount` is `NSPasteboard.changeCount` at that change.
    public func localChange(_ content: ClipboardContent, changeCount: Int) async {
        let ours = ownChanges.remove(changeCount) != nil
        ownChanges = ownChanges.filter { $0 > changeCount } // older own changes can no longer be reported
        guard !ours, sendOn, connected, phoneSupports else { return }
        switch content {
        case .text(let text):
            guard !text.isEmpty else { return }
            guard ClipboardRules.fitsInAFrame(text) else { return setNote("Not sent to your phone: text over 1 MB") }
            do {
                try await send(.clipboardSet(ClipboardSet(itemId: Self.newID(), text: text)))
            } catch {
                return
            }
            history.add(content, direction: .toPhone, id: Self.newID(), date: now())
        case .image(let png):
            guard png.count <= ClipboardLimits.maxImageBytes else { return setNote("Not sent to your phone: image over 10 MB") }
            let item = history.add(content, direction: .toPhone, id: Self.newID(), date: now())
            guard let url = history.imageURL(item) else { return }
            _ = await sendImage(url)
        }
        note = nil
        publish()
    }

    func handle(_ message: Message) async {
        guard case .clipboardSet(let body) = message, receiveOn else { return }
        await applyFromPhone(.text(body.text))
    }

    /// A clipboard image from the phone arrived (TransferManager's `clipboardImageReceived`). The file is removed after.
    public func imageReceived(_ url: URL) async {
        defer { try? FileManager.default.removeItem(at: url) }
        guard receiveOn, let png = try? Data(contentsOf: url) else { return }
        await applyFromPhone(.image(png))
    }

    func connectionChanged(_ status: ConnectionStatus) {
        switch status {
        case .connected(let peer):
            connected = true
            phoneSupports = peer.supports(Feature.clipboard)
        case .disconnected:
            connected = false
        }
        publish()
    }

    /// History "Copy": back on the Mac clipboard, not re-sent (spec §8.2).
    public func copyToMac(id: String) async {
        guard let item = history.item(id: id), let content = history.content(of: item) else { return }
        ownChanges.insert(await apply(content))
    }

    /// History "Send": to the phone again.
    public func sendToPhone(id: String) async {
        guard connected, phoneSupports, let item = history.item(id: id) else { return setNote("Your phone isn't connected") }
        switch history.content(of: item) {
        case .text(let text):
            try? await send(.clipboardSet(ClipboardSet(itemId: Self.newID(), text: text)))
        case .image:
            if let url = history.imageURL(item) { _ = await sendImage(url) }
        case nil:
            break
        }
    }

    public func setSendToPhone(_ on: Bool) { sendOn = on; publish() }
    public func setReceiveFromPhone(_ on: Bool) { receiveOn = on; publish() }
    public func setCapacity(_ value: Int) { history.setCapacity(value); publish() }
    public func clearHistory() { history.clear(); publish() }

    private func applyFromPhone(_ content: ClipboardContent) async {
        ownChanges.insert(await apply(content))
        let item = history.add(content, direction: .fromPhone, id: Self.newID(), date: now())
        publish()
        eventBroadcast.yield(.receivedFromPhone(item))
    }

    private func setNote(_ text: String) {
        note = text
        publish()
    }

    private func publish() {
        state = Self.makeState(history, sendOn, receiveOn, connected, phoneSupports, note)
        stateBroadcast.yield(state)
    }

    private static func makeState(_ history: ClipboardHistory, _ send: Bool, _ receive: Bool, _ connected: Bool, _ supports: Bool, _ note: String?) -> ClipboardState {
        ClipboardState(items: history.items, capacity: history.capacity, sendToPhone: send, receiveFromPhone: receive,
                       connected: connected, phoneSupportsClipboard: supports, note: note)
    }

    static func newID() -> String { UUID().uuidString.lowercased() }
}
```

```kotlin
package dev.macdroid.core.clipboard

import dev.macdroid.core.connection.ConnectionState
import dev.macdroid.core.connection.macSupports

import dev.macdroid.core.protocol.ClipboardSetBody

import dev.macdroid.core.protocol.MessageCodec
import dev.macdroid.core.transfer.OutgoingFile
import java.util.UUID
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.asStateFlow
import kotlinx.coroutines.flow.update

/** One clipboard item on the Clipboard tab's "Recent" list. */
data class ClipItem(val id: String, val kind: Kind, val text: String?, val imageUri: String?, val direction: Direction, val at: Long) {
    enum class Kind { Text, Link, Image }
    enum class Direction { ToMac, FromMac }
}

enum class SendResult { Sent, NotConnected, MacTooOld, Empty, TooLarge }

/** What the app must put on the phone's clipboard. */
sealed interface ClipboardApply {
    data class Text(val text: String) : ClipboardApply
    data class Image(val uri: String, val mime: String) : ClipboardApply
}

/**
 * The phone side of clipboard sync (spec §4.2–4.4): explicit sends (always sent, spec §8.2),
 * received items, and the in-memory "Recent" list. Thread-safe.
 */
class ClipboardHub(
    private val send: (Message) -> Boolean,
    private val enqueueImage: (OutgoingFile) -> Unit,
    private val receiveEnabled: () -> Boolean,
    private val clock: () -> Long = System::currentTimeMillis,
) {
    companion object {
        const val RECENT_LIMIT = 10
        private const val ZERO_ID = "00000000-0000-0000-0000-000000000000"
        private val LINK = Regex("^https?://\\S+$", RegexOption.IGNORE_CASE)

        fun kindOf(text: String): ClipItem.Kind = if (LINK.matches(text.trim())) ClipItem.Kind.Link else ClipItem.Kind.Text

        /** The encoded `clipboard.set` frame, JSON escaping included, fits the 1 MiB limit (spec §8.1). */
        fun fitsInAFrame(text: String): Boolean =
            MessageCodec.encode(Message.ClipboardSet(ClipboardSetBody(ZERO_ID, text = text)), id = ZERO_ID)
                .toByteArray(Charsets.UTF_8).size <= ClipboardLimits.MAX_FRAME_BYTES
    }

    private val _recent = MutableStateFlow<List<ClipItem>>(emptyList())
    val recent: StateFlow<List<ClipItem>> = _recent.asStateFlow()

    fun sendText(text: String?, state: ConnectionState): SendResult {
        val value = text?.takeIf { it.isNotEmpty() } ?: return SendResult.Empty
        reachable(state)?.let { return it }
        if (!fitsInAFrame(value)) return SendResult.TooLarge
        if (!send(Message.ClipboardSet(ClipboardSetBody(UUID.randomUUID().toString(), text = value)))) return SendResult.NotConnected
        record(ClipItem(UUID.randomUUID().toString(), kindOf(value), value, null, ClipItem.Direction.ToMac, clock()))
        return SendResult.Sent
    }

    /** [file] is a PNG the app already wrote to its own storage. */
    fun sendImage(file: OutgoingFile?, state: ConnectionState): SendResult {
        if (file == null) return SendResult.Empty
        reachable(state)?.let { return it }
        if (file.size > ClipboardLimits.MAX_IMAGE_BYTES) return SendResult.TooLarge
        enqueueImage(file)
        record(ClipItem(UUID.randomUUID().toString(), ClipItem.Kind.Image, null, file.source, ClipItem.Direction.ToMac, clock()))
        return SendResult.Sent
    }

    fun handle(message: Message): ClipboardApply? {
        if (message !is Message.ClipboardSet || !receiveEnabled()) return null
        val text = message.body.text
        record(ClipItem(UUID.randomUUID().toString(), kindOf(text), text, null, ClipItem.Direction.FromMac, clock()))
        return ClipboardApply.Text(text)
    }

    fun imageReceived(uri: String, mime: String): ClipboardApply? {
        if (!receiveEnabled()) return null
        record(ClipItem(UUID.randomUUID().toString(), ClipItem.Kind.Image, null, uri, ClipItem.Direction.FromMac, clock()))
        return ClipboardApply.Image(uri, mime)
    }

    fun item(id: String): ClipItem? = _recent.value.firstOrNull { it.id == id }

    private fun reachable(state: ConnectionState): SendResult? = when {
        state !is ConnectionState.Connected -> SendResult.NotConnected
        !state.macSupports(Features.CLIPBOARD) -> SendResult.MacTooOld
        else -> null
    }

    private fun record(item: ClipItem) {
        _recent.update { (listOf(item) + it).take(RECENT_LIMIT) }
    }
}
```

```swift
import AppKit
import MacDroidCore

/// Polls the general pasteboard twice a second (spec §4.1) and reports changes the rules allow.
/// Reading is cheap: only `changeCount` is read until it changes.
@MainActor
final class PasteboardWatcher {
    private var lastChangeCount = NSPasteboard.general.changeCount
    private var timer: Timer?
    private var onChange: ((ClipboardContent, Int) -> Void)?

    func start(onChange: @escaping (ClipboardContent, Int) -> Void) {
        guard timer == nil else { return }
        self.onChange = onChange
        timer = Timer.scheduledTimer(withTimeInterval: 0.5, repeats: true) { [weak self] _ in
            MainActor.assumeIsolated { self?.poll() }
        }
    }

    private func poll() {
        let pasteboard = NSPasteboard.general
        let count = pasteboard.changeCount
        guard count != lastChangeCount else { return }
        lastChangeCount = count
        switch ClipboardRules.kind(of: (pasteboard.types ?? []).map(\.rawValue)) {
        case .ignored:
            return
        case .text:
            if let text = pasteboard.string(forType: .string) ?? pasteboard.string(forType: .URL) { onChange?(.text(text), count) }
        case .image:
            if let png = Self.png(from: pasteboard) { onChange?(.image(png), count) }
        }
    }

    static func png(from pasteboard: NSPasteboard) -> Data? {
        if let png = pasteboard.data(forType: .png) { return png }
        guard let tiff = pasteboard.data(forType: .tiff), let rep = NSBitmapImageRep(data: tiff) else { return nil }
        return rep.representation(using: .png, properties: [:])
    }

    /// Puts an item on the pasteboard and returns the change count it produced (echo prevention, spec §8.2).
    static func write(_ content: ClipboardContent) -> Int {
        let pasteboard = NSPasteboard.general
        pasteboard.clearContents()
        switch content {
        case .text(let text): pasteboard.setString(text, forType: .string)
        case .image(let png): pasteboard.setData(png, forType: .png)
        }
        return pasteboard.changeCount
    }
}
```

```kotlin
package dev.macdroid.app.platform.clipboard

import android.content.Context
import android.graphics.Bitmap
import android.graphics.BitmapFactory
import android.net.Uri
import androidx.core.content.FileProvider
import dev.macdroid.core.transfer.FileNaming
import java.io.File
import java.net.URI
import java.util.UUID

/** Clipboard images in app-private storage (spec §4.3): received ones are shared through a FileProvider. */
object ClipboardImages {
    fun receivedDir(context: Context) = File(context.cacheDir, "clipboard")
    private fun outgoingDir(context: Context) = File(context.cacheDir, "clipboard-out")

    /** A content URI other apps can paste, for a received file (a `file:` URI from the engine). */
    fun contentUri(context: Context, fileUri: String): Uri =
        FileProvider.getUriForFile(context, context.packageName + ".clipboard", File(URI(fileUri)))

    /** Any image the clipboard or the share sheet gives us, as a PNG file in app storage; null if unreadable. */
    fun toPng(context: Context, source: Uri): File? = runCatching {
        val bitmap = context.contentResolver.openInputStream(source)?.use { BitmapFactory.decodeStream(it) } ?: return null
        val dir = outgoingDir(context).apply { mkdirs() }
        val file = File(dir, UUID.randomUUID().toString() + ".png")
        file.outputStream().use { bitmap.compress(Bitmap.CompressFormat.PNG, 100, it) }
        bitmap.recycle()
        prune(dir)
        file
    }.getOrNull()

    /** Keeps the newest [keep] finished files in [dir] (the Recent list shows at most 10). */
    fun prune(dir: File, keep: Int = 10) {
        dir.listFiles { file -> !file.name.endsWith(FileNaming.PART_SUFFIX) }
            ?.sortedByDescending { it.lastModified() }
            ?.drop(keep)
            ?.forEach { it.delete() }
    }
}
```

```kotlin
import dev.macdroid.core.transfer.OutgoingFile
import dev.macdroid.core.transfer.TransferEngine
import dev.macdroid.core.transfer.TransferEvent
import java.io.File
import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.launch
import kotlinx.coroutines.withContext

/** Connects the Mac's clipboard items to Android's clipboard, and the phone's explicit sends to the Mac (spec §4.2–4.3). */
class ClipboardBridge(
    private val context: Context,
    private val connection: ConnectionManager,
    private val engine: TransferEngine,
    val prefs: ClipboardPrefs,
    private val scope: CoroutineScope,
) {
    val hub = ClipboardHub(connection::send, { engine.enqueueClipboard(it) }, { prefs.receiveFromMac.value })
    private val clipboard = context.getSystemService(ClipboardManager::class.java)

    fun start() {
        scope.launch { connection.incoming.collect { message -> hub.handle(message)?.let { apply(it) } } }
        scope.launch {
            engine.events.collect { event ->
                if (event is TransferEvent.ClipboardReceived) hub.imageReceived(event.uri, event.mime)?.let { apply(it) }
            }
        }
    }

    /** Sends what was on the clipboard. Read [clip] in a focused activity, which Android requires; the rest runs off the main thread. */
    suspend fun sendClip(clip: ClipData?): SendResult = withContext(Dispatchers.IO) {
        val data = clip?.takeIf { it.itemCount > 0 } ?: return@withContext SendResult.Empty
        val item = data.getItemAt(0)
        val uri = item.uri
        if (uri != null && data.description.hasMimeType("image/*")) sendImage(uri)
        else hub.sendText(item.coerceToText(context)?.toString(), connection.state.value)
    }

    /** "Copy to Mac" from the share sheet: shared text, or a single image. */
    suspend fun sendShared(text: String?, image: Uri?): SendResult = withContext(Dispatchers.IO) {
        if (image != null) sendImage(image) else hub.sendText(text, connection.state.value)
    }

    /** Recent → tap: copy it to this phone's clipboard again. */
    fun copyLocally(item: ClipItem) {
        val clip = when {
            item.kind == ClipItem.Kind.Image && item.imageUri != null -> imageClip(item.imageUri)
            else -> ClipData.newPlainText("MacDroid", item.text.orEmpty())
        } ?: return
        runCatching { clipboard.setPrimaryClip(clip) }
    }

    private fun sendImage(source: Uri): SendResult {
        val png = ClipboardImages.toPng(context, source)
        val file = png?.let { OutgoingFile(it.path, "clipboard.png", it.length(), "image/png") }
        return hub.sendImage(file, connection.state.value)
    }

    private suspend fun apply(item: ClipboardApply) = withContext(Dispatchers.Main) {
        val clip = when (item) {
            is ClipboardApply.Text -> ClipData.newPlainText("From your Mac", item.text)
            is ClipboardApply.Image -> imageClip(item.uri)
        } ?: return@withContext
        runCatching { clipboard.setPrimaryClip(clip) } // allowed in the background (spec §4.3)
        ClipboardImages.prune(ClipboardImages.receivedDir(context))
    }

    /** Received images are `file:` URIs in the clipboard folder; images we sent are plain paths of PNG copies. */
    private fun imageClip(uriOrPath: String): ClipData? = runCatching {
        val fileUri = if (uriOrPath.startsWith("/")) File(uriOrPath).toURI().toString() else uriOrPath
        ClipData.newUri(context.contentResolver, "Image", ClipboardImages.contentUri(context, fileUri))
    }.getOrNull()
}
```
